附录 A 几个常用定理的证明

定理 A.1 设 A 和 B 是两个彼此非对易的算符，\xi 是参数（c 数），则有

\mathrm{e}^{\xi A} B\mathrm{e}^{-\xi A} = B + \xi [A, B] + \frac{\xi^2}{2!} [A, [A, B]] + \cdots

证明：令

f(\xi) = \mathrm{e}^{\xi A} B\mathrm{e}^{-\xi A}(A.1)

将 f(\xi) 按 \xi 的幂次方展开，即

f(\xi) = f(0) + f'(0)\xi + \frac{1}{2!} f''(0)\xi^2 + \cdots(A.2)

注意到

f(0) = B
f'(0) = \frac{\mathrm{d}f(\xi)}{\mathrm{d}\xi} \bigg|_{\xi=0} = [A, f(\xi)] \bigg|_{\xi=0} = [A, B]
f'(0) = \frac{\mathrm{d}^2 f(\xi)}{\mathrm{d}\xi^2} \bigg|_{\xi=0} = [A, f'(\xi)] \bigg|_{\xi=0} = [A, [A, f(\xi)]] \bigg|_{\xi=0} = [A, [A, B]](A.3)

将式(A.3)代入式(A.2)即可得证。

f(\xi) = \mathrm{e}^{\xi A} \mathrm{e}^{\xi B}(A.4)

附录 B 求解薛定谔方程的一般过程

我们的目的是求解薛定谔方程

\mathrm{i} \frac{\mathrm{d}}{\mathrm{d}t} |\psi(t)\rangle = H |\psi(t)\rangle

一般情况下，总哈密顿量可以写为自由哈密顿量和相互作用哈密顿量之和，即

H = H_0 + V

设自由哈密顿量 H_0 的本征态为 |B_k\rangle（B：bare states，裸态），例如 |e\rangle，|g\rangle，…，将 |\psi(t)\rangle 用 |B_k\rangle 展开 (H_0 表象），有

|\psi(t)\rangle = \sum_k b_k(t) |B_k\rangle, \quad b_k(t) = \langle B_k |\psi(t)\rangle

则问题转化为求出 b_k(t)。

另一方面，设总哈密顿量 H 的本征方程为

H |D_j\rangle = \lambda_j |D_j\rangle, \quad D\text{为，缀饰态}

将 |\psi(t)\rangle 用 |D_j\rangle 展开 (H 表象），即

|\psi(t)\rangle = \sum_j d_j(t) |D_j\rangle, \quad d_j(t) = \langle D_j |\psi(t)\rangle

则问题转化为求 d_j(t)。

下面建立 b_k(t) 与 d_j(t) 之间的关系（表象变换），由

|\psi(t)\rangle = \sum_k b_k(t) |B_k\rangle = \sum_j d_j(t) |D_j\rangle

可得

b_k(t) = \langle B_k |\psi(t)\rangle = \langle B_k |\sum_j d_j(t) |D_j\rangle = \sum_j d_j(t) \langle B_k |D_j\rangle = \sum_j d_j(t) u_{kj}

其中，u_{kj} = \langle B_k |D_j\rangle，因此若求得 d_j(t) 即可得到 b_k(t)。

下面求解 d_j(t)，将 |\psi(t)\rangle = \sum_j d_j(t) |D_j\rangle 代入薛定谔方程，可得

\mathrm{i} \frac{\mathrm{d}}{\mathrm{d}t} d_j(t) = \langle D_j |H |\psi\rangle = \lambda_j d_j(t), \quad d_j(t) = d_j(0) \mathrm{e}^{-\mathrm{i}\lambda_j t}

于是，有

b_k(t) = \sum_j d_j(t) u_{kj} = \sum_j d_j(0) \mathrm{e}^{-\mathrm{i}\lambda_j t} u_{kj}

一般情况下，初始条件是由裸态 b_k(0)，而不是由缀饰态 d_j(0)给出，因此我们需要将 d_j(0) 用 b_k(0) 表示，即

d_j(0) = \langle D_j | \psi(0) \rangle = \langle D_j | \sum_k b_k(0) | B_k \rangle = \sum_k b_k(0) \langle D_j | B_k \rangle = \sum_k b_k(0) u_{kj}^*

于是，得

b_m(t) = \sum_j d_j(t) u_{mj}
= \sum_j d_j(0) \mathrm{e}^{-\mathrm{i}\lambda_j t} u_{mj}
= \sum_j \left(\sum_k b_k(0) u_{kj}^*\right) \mathrm{e}^{-\mathrm{i}\lambda_j t} u_{mj}
= \sum_k \left(\sum_j \mathrm{e}^{-\mathrm{i}\lambda_j t} u_{kj}^* u_{mj}\right) b_k(0)

上述求解过程可概括如下。

求解薛定谔方程，即

\mathrm{i} \frac{\mathrm{d}}{\mathrm{d}t} |\psi(t)\rangle = H |\psi(t)\rangle(B.1)

将 |\psi(t)\rangle 用 H_0 的本征态(裸态) |B_k\rangle 展开为

| \psi(t)\rangle = \sum_k b_k(t) |B_k\rangle(B.2)

求得展开系数为

b_m(t) = \sum_k \left(\sum_j \mathrm{e}^{-\mathrm{i}\lambda_j t} u_{kj}^* u_{mj}\right) b_k(0)(B.3)

其中，u_{kj} = \langle B_k | D_j \rangle，|B_k\rangle 为自由哈密顿量 H_0 的本征态，|D_j\rangle 为总哈密顿量 H 的本征态；\lambda_j 为 H 的本征值。

附录 C 电偶极相互作用与磁偶极相互作用

我们知道，电磁场既有电场分量，也有磁场分量。在研究电磁场与物质的相互作用时，经常仅考虑电场的作用，而不考虑磁场的作用，这是为什么呢？

电场的作用主要是原子的电偶极矩与电场之间的电偶极相互作用，其相互作用能为

U_e = -\bm{d} \cdot \bm{E} = -e\bm{r} \cdot \bm{E} \propto -ea_B E

其中，e 为电子电荷；\bm{d} = e\bm{r} 为原子的电偶极矩；a_B 为原子的玻尔半径；\bm{E} 为电场矢量。

磁场的作用主要为原子的磁偶极矩与磁场之间的磁偶极相互作用，其相互作用能为

U_m = -\bm{\mu} \cdot \bm{B} \propto -\mu_B B

其中，\bm{\mu} 为原子的磁偶极矩；\mu_B 为原子的玻尔磁子；\bm{B} 为磁场矢量。

磁偶极相互作用能与电偶极相互作用能的比值为

\frac{U_m}{U_e} \propto \frac{\mu_B B}{ea_B E} = \frac{(e \hbar / 2m)}{e(\hbar^2 / me^2)} \frac{B}{E} = \frac{1}{2} \frac{e^2}{\hbar c} = \frac{1}{2} \alpha = \frac{1}{2} \times \frac{1}{137}

可见，磁偶极相互作用比电偶极相互作用弱两个数量级，因此在研究电磁场与物质相互作用时，在许多情况下只考虑电场的作用，而不考虑磁场的作用。

附录 D 有效哈密顿量[1]

在研究电磁场与原子的相互作用时，在将系统的哈密顿量变换到相互作用绘景后，我们经常会遇到下列形式的哈密顿量，即

H(t) = \sum_{m} h_{m}^{+} \mathrm{e}^{\mathrm{i}\Delta_{m} t} + \mathrm{H. c.}(D.1)

其中，h_{m}^{+} 是电磁场算符和原子算符的组合；\Delta_{m} 是电磁场频率与原子跃迁频率的失谐量；H. c. 表示厄米共轭。

(1) 二能级原子与经典单模电磁场的相互作用

H(t) = \hbar \Omega \sigma^{+} \mathrm{e}^{\mathrm{i}\Delta t} + \mathrm{H. c.}(D.2)

其中，\Omega 是描述电磁场与原子相互作用强度的 Rabi 频率；\sigma^{+} = |e\rangle \langle g|, |e\rangle 和 |g\rangle 分别是原子的上下能态；\Delta = \omega_{a} - \omega_{f}, \omega_{a} 和 \omega_{f} 分别是原子跃迁频率和电磁场频率。

将式(D.2)与式(D.1)比较可知，h_{m}^{+} = \hbar \Omega \sigma^{+}, \Delta_{m} = \Delta。

(2) 二能级原子与量子单模电磁场的相互作用(JC模型)

H(t) = \hbar g \sigma^{+} a \mathrm{e}^{\mathrm{i}\Delta t} + \mathrm{H. c.}(D.3)

其中，g 是描述电磁场与原子相互作用的耦合常数，a 是电磁场的光子湮灭算符，其他符号的意义与上面相同。

将(D.3)式与(D.1)式比较可知，h_{m}^{+} = \hbar \Omega \sigma^{+} a, \Delta_{m} = \Delta。

(3) 三能级原子与经典双模电磁场的相互作用(以 \Lambda 型相互作用为例)

H(t) = \hbar \Omega_{1} \sigma_{ab} \mathrm{e}^{\mathrm{i}\Delta_{1} t} + \hbar \Omega_{2} \sigma_{ac} \mathrm{e}^{\mathrm{i}\Delta_{2} t} + \mathrm{H. c.}(D.4)

其中，\sigma_{jk} = |j\rangle \langle k| (j, k = a, b, c)，其他符号的意义与上面类似。

将式(D.4)与式(D.1)比较可知，h_{1}^{+} = \hbar \Omega_{1} \sigma_{ab}, h_{2}^{+} = \hbar \Omega_{2} \sigma_{ac}。

(4) 三能级原子与量子双模电磁场的相互作用(以 \Lambda 型相互作用为例)

\hat{x} = \sqrt{\frac{\hbar}{2\nu M}} \left(a^+ \mathrm{e}^{\mathrm{i}\nu t} + a \mathrm{e}^{-\mathrm{i}\nu t}\right)(D.25)
k_L \hat{x}(t) = \eta \left(a^+ \mathrm{e}^{\mathrm{i}\nu t} + a \mathrm{e}^{-\mathrm{i}\nu t}\right)(D.26)

其中, \eta = k_L \sqrt{\hbar / (2\nu M)} 称为 Lamb-Dicke 参数。

一般情况下，\eta \ll 1（称为 Lamb-Dicke 范围），从而 k_{L} \hat{x}(t) 很小。

在 Lamb-Dicke 范围，有

\mathrm{e}^{\mathrm{i}k_{L} \hat{x}(t)} \approx 1 + \mathrm{i}k_{L} \hat{x}(t) = 1 + \mathrm{i}\eta \left(a^{+} \mathrm{e}^{\mathrm{i}\nu t} + a \mathrm{e}^{-\mathrm{i}\nu t}\right)(D.27)
H(t) = \hbar \Omega \sigma_{eg} \left[ 1 + \mathrm{i}\eta \left(a^{+} \mathrm{e}^{\mathrm{i}\nu t} + a \mathrm{e}^{-\mathrm{i}\nu t}\right) \right] \mathrm{e}^{\mathrm{i}\Delta t} + \mathrm{H. c.}(D.28)

将式(D.28)与式(D.1)比较，可知

h_{1}^{+} = \hbar \Omega \sigma_{eg}, \quad \Delta_{1} = \Delta(D.29a)
h_{2}^{+} = \mathrm{i}\eta \hbar \Omega \sigma_{eg} a^{+}, \quad \Delta_{2} = \Delta + \nu(D.29b)
h_{3}^{+} = \mathrm{i}\eta \hbar \Omega \sigma_{eg} a, \quad \Delta_{3} = \Delta - \nu(D.29c)

将式(D.29)代入式(D.15)，可得

\begin{aligned} H_{\mathrm{eff}}={}&\hbar\frac{\Omega^2}{\Delta}(\sigma_{ee}-\sigma_{gg})\\ &+\hbar\frac{(\eta\Omega)^2}{\Delta+\nu}[\hat n\sigma_{ee}-(\hat n+1)\sigma_{gg}]\\ &+\hbar\frac{(\eta\Omega)^2}{\Delta-\nu}[(\hat n+1)\sigma_{ee}-\hat n\sigma_{gg}]\\ &+\left[\hbar\frac{-\mathrm{i}\eta\hbar\Omega^2}{\Delta+\nu/2}(\sigma_{ee}-\sigma_{gg})a\mathrm{e}^{-\mathrm{i}\nu t}+\mathrm{H.c.}\right]\\ &+\left[\hbar\frac{(\eta\Omega)^2}{\Delta}(\sigma_{ee}-\sigma_{gg})a^{+2}\mathrm{e}^{\mathrm{i}2\nu t}+\mathrm{H.c.}\right] \end{aligned}(D.30)

略去最后两项（含 \mathrm{e}^{-\mathrm{i}\nu t} 和 \mathrm{e}^{\mathrm{i}2\nu t} 的快速振荡项），由前三项可得

H_{\mathrm{eff}} = \hbar \frac{\Omega^{2}}{\Delta} \left[ 1 + \frac{2 (\eta \Delta)^{2}}{\Delta^{2} - \nu^{2}} \left(\hat{n} + \frac{1}{2}\right) \right] \left(\sigma_{ee} - \sigma_{gg}\right)(D.31)

其中，\hat{n} = a^{+} a。
