第 3 章　电磁场物理量的算符表示

第 2 章我们介绍了经典电磁场与原子的相互作用。从本章到第 6 章我们将集中介绍量子化电磁场本身的一些性质，包括电磁场物理量的算符表示、电磁场的量子态、电磁场量子态在相干态表象中的表示（又称为电磁场量子态在相空间中的表示，或称为电磁场量子态的准概率分布函数）、电磁场的相干性等。本章介绍电磁场物理量的算符表示[1–20]。

我们知道，在量子力学中力学量(物理量)用算符表示，量子态用态矢量或密度算符表示。所谓电磁场的量子化，就是把描述电磁场的物理量（电场强度 \bm{E}、磁感应强度 \bm{B}、能量 H 等）用算符表示，把电磁场的状态用态矢量或密度算符表示。

下面我们从经典的麦克斯韦方程组出发，将电磁场的电场强度 \bm{E} 和磁感应强度 \bm{B} 分别用驻波和行波展开，计算电磁场的总能量 H，通过与谐振子的能量表达式进行比较，发现在形式上电磁场的一个模式与一个一维谐振子相同。从而利用一维谐振子的量子化方法，可将电磁场量子化。具体来讲，通过引入光子湮灭算符 a 和光子产生算符 a^{+}，把描述电磁场的物理量，如电场强度、磁感应强度，以及总能量等用算符表示。

从经典电动力学我们知道，真空中无源电磁场可以用下列麦克斯韦方程组描述，即

\nabla \times \bm{E} = -\frac{\partial \bm{B}}{\partial t}(3.1)
\nabla \times \bm{B} = \frac{1}{c^{2}}\frac{\partial \bm{E}}{\partial t}(3.2)
\nabla \cdot \bm{B} = 0(3.3)
\nabla \cdot \bm{E} = 0(3.4)

其中，c = 1/\sqrt{\mu_{0}\varepsilon_{0}} 为真空中的光速；\mu_{0} 和 \varepsilon_{0} 分别为真空磁导率和真空介电常数。

为了比较，下面给出在介质中的有源麦克斯韦方程组，即

\nabla \times \bm{E} = -\frac{\partial \bm{B}}{\partial t}(3.1')
\nabla \times \bm{H} = \bm{J} + \frac{\partial \bm{D}}{\partial t}(3.2')
\nabla \cdot \bm{B} = 0(3.3')
\nabla \cdot \bm{D} = \rho(3.4')

其中, \rho 和 \bm{J} 分别为自由电荷密度和自由电流密度; \bm{D} = \varepsilon\bm{E}; \bm{H} = \bm{B} / \mu, \mu 和 \varepsilon 分别为介质的磁导率和介电常数。

3.1　电磁场的驻波(正则模)形式

首先考虑一维谐振腔中的电磁场，如图 3.1 所示。设腔轴沿 z 方向，腔长为 L。

设电场沿 x 方向偏振，即 \bm{E}(\bm{r},t) = \bm{e}_x E_x(z,t)，这里 \bm{e}_x 为 x 方向的单位矢量，将 E_x(z,t) 用正则模(驻波)展开，有

E_x(z,t) = \sum_j A_j q_j(t) \sin(k_j z) \equiv \sum_j E_j(3.5)

其中，k_j = \mathrm{j}\pi / L (j = 1,2,\cdots)（由 E_x(L,t) = 0, \sin(k_j L) = 0 定出）为第 j 个场模的波数，假设 q_j(t) 具有长度的量纲，A_j 为待定常数[1]。由麦克斯韦方程组可知，对现在考虑的情况，磁场沿 y 方向，即 \bm{B}(\bm{r},t) = \bm{e}_y B_y(z,t)，由式(3.2)有

-\frac{\partial B_y}{\partial z} = \frac{1}{c^2} \frac{\partial E_x}{\partial t}(3.6a)
B_y(z,t) = \frac{1}{c} \sum_j \frac{A_j}{\omega_j} \frac{p_j(t)}{m_j} \cos(k_j z) \equiv \sum_j B_j(3.6b)

其中，c = 1 / \sqrt{\mu_0 \varepsilon_0} 为真空中的光速；\omega_j = c k_j 为第 j 个场模的角频率；p_j(t) / m_j = \mathrm{d}q_j(t) / \mathrm{d}t; m_j 具有质量的量纲；p_j(t) 具有动量的量纲。

电磁场的总能量为

H = \frac{1}{2} \int \mathrm{d}v \left( \varepsilon_0 \bm{E}^2 + \frac{1}{\mu_0} \bm{B}^2 \right)

其中, B_{j}^{(s)} = \frac{E_{j}^{(s)}}{c}。

关于驻波(正则模)形式的另一种讨论, 可以通过下列两式引入电磁场的矢量势 \bm{A} 和标量势 \Phi, 即

\bm{B} = \nabla \times \bm{A}(3.22a)
\bm{E} = -\frac{\partial \bm{A}}{\partial t} - \nabla \Phi(3.22b)

选择 Coulomb 规范, 即 \nabla \cdot \bm{A} = 0, \Phi = 0, 则

\bm{B} = \nabla \times \bm{A}(3.23a)
\bm{E} = -\frac{\partial \bm{A}}{\partial t}(3.23b)

由麦克斯韦方程组可得

\nabla^{2}\bm{A} = \frac{1}{c^{2}}\frac{\partial^{2}\bm{A}}{\partial t^{2}}(3.24)

利用分离变量法, 可将 \bm{A} 展开为

\bm{A}(\bm{r},t) = \sum_{j} A_{j}^{(0)} \left[a_{j}(t)\bm{u}_{j}(\bm{r}) + \mathrm{C.C.}\right](3.25)

式中, A_{j}^{(0)} 为待定常数; a_{j}(t) 和 \bm{u}_{j}(\bm{r}) 分别满足如下方程, 即

\nabla^{2}\bm{u}_{j}(\bm{r}) + k_{j}^{2}\bm{u}_{j}(\bm{r}) = 0(3.26a)
\frac{\mathrm{d}^{2}a_{j}(t)}{\mathrm{d}t^{2}} + \omega_{j}^{2}a_{j}(t) = 0(3.26b)

式中, \omega_{j} = ck_{j}; a_{j}(t) 可取 \sin(\omega_{j}t)、\cos(\omega_{j}t) 或 \mathrm{e}^{\pm\mathrm{i}\omega_{j}t}, 这里取 a_{j}(t) = a_{j}\mathrm{e}^{-\mathrm{i}\omega_{j}t}; \bm{u}_{j}(\bm{r}) 取 \sin(\bm{k}_{j} \cdot \bm{r})、\cos(\bm{k}_{j} \cdot \bm{r}) 或 \mathrm{e}^{\pm\mathrm{i}\bm{k}_{j} \cdot \bm{r}}, 这里根据边界条件选取。

式(3.22)～式(3.26)既适用于驻波场, 也适用于行波场。

3.2　电磁场的行波形式

前面已导出

\bm{A}(\bm{r},t) = \sum_{j} A_{j}^{(0)} \left[ a_{j}(t) \bm{u}_{j}(\bm{r}) + \mathrm{C. C.} \right]

其中，A_{j}^{(0)} 为待定常数；a_{j}(t) 和 \bm{u}_{j}(\bm{r}) 分别满足如下方程，即

\nabla^{2} \bm{u}_{j}(\bm{r}) + k_{j}^{2} \bm{u}_{j}(\bm{r}) = 0
\frac{\mathrm{d}^{2} a_{j}(t)}{\mathrm{d} t^{2}} + \omega_{j}^{2} a_{j}(t) = 0

其中，\omega_{j} = c k_{j}；a_{j}(t)，可取 \sin(\omega_{j} t)、\cos(\omega_{j} t) 或 \mathrm{e}^{\pm \mathrm{i} \omega_{j} t}，这里取 a_{j}(t) = a_{j} \mathrm{e}^{-\mathrm{i} \omega_{j} t}；\bm{u}_{j}(\bm{r}) 可取 \sin(\bm{k}_{j} \cdot \bm{r})、\cos(\bm{k}_{j} \cdot \bm{r}) 或 \mathrm{e}^{\pm \mathrm{i} \bm{k}_{j} \cdot \bm{r}}，这里根据边界条件选取。

为了讨论在自由空间传播的电磁场的量子化，可以考虑存在于一个大而有限的立方体（边长为 L）中的电磁场，将电磁场用行波（平面波）展开。为此，取 \bm{u}_{j}(\bm{r}) = u_{j}(\bm{r}) \bm{e}_{j} = \mathrm{e}^{\mathrm{i} \bm{k}_{j} \cdot \bm{r}} \bm{e}_{j}。

利用周期性边界条件，即

\bm{u}_{j}(\bm{r} + L \bm{e}_{x}) = \bm{u}_{j}(\bm{r} + L \bm{e}_{y}) = \bm{u}_{j}(\bm{r} + L \bm{e}_{z}) = \bm{u}_{j}(\bm{r})(3.37)

可得

\bm{k}_{j} = \frac{2 \pi}{L} \left(l_{j} \bm{e}_{x} + m_{j} \bm{e}_{y} + n_{j} \bm{e}_{z}\right)(3.38)

其中，(l_{j}, m_{j}, n_{j}) 为正整数。

将 a_{j}(t) = a_{j} \mathrm{e}^{-\mathrm{i} \omega_{j} t} 和 \bm{u}_{j}(\bm{r}) = \bm{e}_{j} \mathrm{e}^{\mathrm{i} \bm{k}_{j} \cdot \bm{r}} 代入 \bm{A}(\bm{r},t) 的式(3.25)，并将待定常数改为 A_{j}^{(r)}，其上标(r)表示行波(running wave)，可得

\bm{A}(\bm{r},t) = \sum_{j} \bm{e}_{j} A_{j}^{(r)} \left[ a_{j} \mathrm{e}^{-\mathrm{i} (\omega_{j} t - \bm{k}_{j} \cdot \bm{r})} + a_{j}^{*} \mathrm{e}^{\mathrm{i} (\omega_{j} t - \bm{k}_{j} \cdot \bm{r})} \right](3.39)

利用 \bm{E} = -\frac{\partial \bm{A}}{\partial t} 和 \bm{B} = \nabla \times \bm{A}，可得

H = \sum_{j} \frac{1}{2} \hbar \omega_{j} \left(a_{j} a_{j}^{*} + a_{j}^{*} a_{j}\right) = \sum_{j} H_{j}(3.43)

若将 a_{j} 和 a_{j}^{*} \rightarrow a_{j}^{+} 看作算符，并令 \left[a_{j}, a_{j}^{+}\right] = 1（量子化），则有

H = \sum_{j} \hbar \omega_{j} \left(a_{j}^{+} a_{j} + \frac{1}{2}\right) = \sum_{j} H_{j}(3.43')

将 A_{j}^{(r)} = \sqrt{\frac{\hbar}{2 V \varepsilon_{0} \omega_{j}}} 代入 \bm{A}(\boldsymbol{r}, t)、\bm{E}(\boldsymbol{r}, t) 和 \bm{B}(\boldsymbol{r}, t) 的表达式，并将 a_{j} 和 a_{j}^{*} \rightarrow a_{j}^{+} 看作算符，则得

\bm{A}(\boldsymbol{r}, t) = \sum_{j} \bm{e}_{j} \sqrt{\frac{\hbar}{2 V \varepsilon_{0} \omega_{j}}} \left[ a_{j} \mathrm{e}^{-\mathrm{i}(\omega_{j} t - \bm{k}_{j} \cdot \boldsymbol{r})} + a_{j}^{+} \mathrm{e}^{\mathrm{i}(\omega_{j} t - \bm{k}_{j} \cdot \boldsymbol{r})} \right] = \sum_{j} \bm{A}_{j}(\boldsymbol{r}, t)(3.44)
\bm{E}(\boldsymbol{r}, t) = \mathrm{i} \sum_{j} \bm{e}_{j} E_{j}^{(r)} \left\{a_{j} \mathrm{e}^{-\mathrm{i}(\omega_{j} t - \bm{k}_{j} \cdot \boldsymbol{r})} - a_{j}^{+} \mathrm{e}^{\mathrm{i}(\omega_{j} t - \bm{k}_{j} \cdot \boldsymbol{r})} \right\} = \sum_{j} \bm{E}_{j}(\boldsymbol{r}, t)(3.45)
\bm{B}(\boldsymbol{r}, t) = \mathrm{i} \sum_{j} \left(\frac{\boldsymbol{k}_{j}}{k_{j}} \times \bm{e}_{j}\right) \frac{E_{j}^{(r)}}{c} \left\{a_{j} \mathrm{e}^{-\mathrm{i}(\omega_{j} t - \bm{k}_{j} \cdot \boldsymbol{r})} - a_{j}^{+} \mathrm{e}^{\mathrm{i}(\omega_{j} t - \bm{k}_{j} \cdot \boldsymbol{r})} \right\} = \sum_{j} \bm{B}_{j}(\boldsymbol{r}, t)(3.46)

其中，E_{j}^{(r)} = \sqrt{\frac{\hbar \omega_{j}}{2V\varepsilon_{0}}}，(r)表示行波；\bm{e}_{j}表示第 j 个场模偏振方向的单位矢量；\bm{k}_{j}表示第 j 个场模的波矢量。

根据 \nabla \cdot \bm{E} = 0，可知 \bm{k}_{j} \cdot \bm{e}_{j} = 0，即电磁波是横波，因此对于每一个给定的波矢量 \bm{k}_{j}，存在两个独立的偏振方向 \bm{e}_{j}。

由上面的讨论可知，在电磁场的电场强度算符 \bm{E}、磁感应强度算符 \bm{B}，以及能量算符（哈密顿量）H 的表达式中均出现算符 a_{j} 和 a_{j}^{+}。因此，算符 a_{j} 和 a_{j}^{+} 在量子光学中起着非常重要的作用。由后面的讨论可以知道，a_{j} 和 a_{j}^{+} 分别为电磁场的光子湮灭算符和产生算符。

另外，有时将式(3.45)分解成所谓的正频部分和负频部分，即

\bm{E}(\bm{r},t) = \bm{E}^{(+)}(\bm{r},t) + \bm{E}^{(-)}(\bm{r},t)(3.47)

其中

\bm{E}^{(+)}(\bm{r},t) = \mathrm{i} \sum_{j} \bm{e}_{j} E_{j}^{(r)} a_{j} \mathrm{e}^{-\mathrm{i}(\omega_{j} t - \bm{k}_{j} \cdot \bm{r})}(3.48)
\bm{E}^{(-)}(\bm{r},t) = \left[ \bm{E}^{(+)}(\bm{r},t) \right]^{+}(3.49)

正频部分 \bm{E}^{(+)}(\bm{r},t) \propto a_{k}，而负频部分 \bm{E}^{(-)}(\bm{r},t) \propto a_{k}^{+}。这种分解不只是为了数学上的方便，而是具有重要物理意义的（见后面有关章节）。

最后，将主要公式罗列如下（后面要经常用到），即

\bm{E} = \sum_{j} \bm{E}_{j}, \quad \bm{B} = \sum_{j} \bm{B}_{j}, \quad H = \sum_{j} H_{j}

(1) 驻波形式（一维情况）

E_{j}(z,t) = E_{j}^{(s)} \sin(k_{j} z) \left[ a_{j} \mathrm{e}^{-\mathrm{i}\omega_{j} t} + a_{j}^{+} \mathrm{e}^{\mathrm{i}\omega_{j} t} \right]
B_{j}(z,t) = -\mathrm{i} B_{j}^{(s)} \cos(k_{j} z) \left[ a_{j} \mathrm{e}^{-\mathrm{i}\omega_{j} t} - a_{j}^{+} \mathrm{e}^{\mathrm{i}\omega_{j} t} \right]

或

E_{j} = \mathrm{i} E_{j}^{(0)} \sin(k_{j} z) \left[ a_{j} \mathrm{e}^{-\mathrm{i}\omega_{j} t} - a_{j}^{+} \mathrm{e}^{\mathrm{i}\omega_{j} t} \right]
B_{j} = B_{j}^{(0)} \cos(k_{j} z) \left[ a_{j} \mathrm{e}^{-\mathrm{i}\omega_{j} t} + a_{j}^{+} \mathrm{e}^{\mathrm{i}\omega_{j} t} \right]

其中，E_{j}^{(s)} = E_{j}^{(0)} = \sqrt{\hbar \omega_{j} / V\varepsilon_{0}}；B_{j}^{(s)} = B_{j}^{(0)} = E_{j}^{(0)} / c。

(2) 行波形式

\bm{E}_{j}(\bm{r},t) = \mathrm{i} \bm{e}_{j} E_{j}^{(r)} \left\{ a_{j} \mathrm{e}^{-\mathrm{i}(\omega_{k} t - \bm{k}_{j} \cdot \bm{r})} - a_{j}^{+} \mathrm{e}^{\mathrm{i}(\omega_{k} t - \bm{k}_{j} \cdot \bm{r})} \right\}
\bm{B}_{j}(\bm{r},t) = \mathrm{i} \left(\frac{\bm{k}_{j}}{k_{j}} \times \bm{e}_{j}\right) B_{j}^{(r)} \left\{ a_{j} \mathrm{e}^{-\mathrm{i}(\omega_{k} t - \bm{k}_{j} \cdot \bm{r})} - a_{j}^{+} \mathrm{e}^{\mathrm{i}(\omega_{k} t - \bm{k}_{j} \cdot \bm{r})} \right\}

其中，E_{j}^{(r)} = \sqrt{\hbar \omega_{j} / 2V\varepsilon_{0}}；B_{j}^{(r)} = E_{j}^{(r)} / c。
