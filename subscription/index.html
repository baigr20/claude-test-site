ChatGPT 订阅查询

登录自己的 ChatGPT 后打开会话数据页面，把 JSON 贴回来。本页经查询节点核对套餐、额度、到期和续费，会话只在内存中短暂使用。

这份 JSON 含登录凭证。 不要把它发给别人。查询完成后输入会自动清空；取消、恢复续费和账单入口走本站接口，会话不写入磁盘。
输入

会话 JSON

打开 会话数据页面，粘贴完整内容，或只保留 accessToken、sessionToken 的精简 JSON。仅有 accessToken 时可尝试查询，需要浏览器会话的操作仍需 sessionToken。

查询完成后，本页输入会自动清空。

说明

这次能查到什么

  • 套餐、到期时间和自动续费状态。
  • Codex 剩余额度和 ChatGPT 功能次数。
  • 卡付账单入口；Apple / Google 订阅请到原支付平台管理。

NX 工具箱是独立的实用页面，不是 OpenAI 或其他厂商的官方站点。

ChatGPT 订阅查询会经本站接口向 ChatGPT 核对，会话不落盘。请不要把真实会话发到聊天或不信任的环境。
