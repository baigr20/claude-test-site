说明

怎么算

  • 剩余天数只看状态为生效、并且带到期时间的记录。不足一天按 1 天向上取整；刚过期显示剩余 0 天。
  • 同一份 JSON 里的 X 订阅会显示档位和是否生效。X 对象如果是空的，就没有到期时间，不算剩余天数。
  • 未生效记录里的未来账期不计入剩余天数。主套餐名称来自 dominantPlan。
  • X 自己的订阅接口要带登录请求头，不能像这个 Grok 地址一样直接打开复制，所以本页不代查 x.com。

NX 工具箱是独立的实用页面，不是 xAI、X 或其他厂商的官方站点。
